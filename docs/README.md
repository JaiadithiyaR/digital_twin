## Superseded / not yet rebuilt for OAI

- **`IEEE_Digital_Twin_Paper.docx`** — predates the OAI migration: it describes the retired
  NS-3/5G-LENA simulated-telemetry architecture and the 5 retired DT components (throughput/
  latency/packet_loss/prb_utilization/jitter), not the current 7-component OAI replay design.
  **Do not edit this file.** It is kept for historical reference only; treat it as superseded by
  this `docs/` directory (principally `MODELS.md`/`oai_twin.md`) for anything describing current
  system behavior. No updated LaTeX or `.docx` paper has been produced for the OAI architecture
  as of this revision — this is a genuine, currently-open gap (see `IMPLEMENTATION_STATUS.md`),
  not something to assume exists elsewhere.
- **`FORMULAS.pdf`** — same situation: predates the OAI migration, not yet rebuilt. The
  fidelity formula itself (RMSE/MAE/Wasserstein/MK-MMD → composite → unified score) is
  unchanged by the migration (only the component set feeding it changed — see `CLAUDE.md`'s
  Phase 12 entry), so this PDF's actual formula content remains accurate even though its
  surrounding component-set prose does not; treat `CLAUDE.md` §5 as authoritative over any
  conflict.
